# VikMix DJ

Professional mobile-first two-deck DJ remix mixer powered by YouTube IFrame API and dual-deck crossfade engine.

## Features
- Dual interactive YouTube decks with independent EQ, cueing, loop, and tempo controls
- REWIND MIX transition engine with instant vinyl brake, reverse spin, and automatic crossfade
- Viral Meme Sound Library with background music ducking & restoration
- Full PWA & native Android APK support via Capacitor

## Android APK Build
GitHub → Actions → Build Android APK → Run workflow → Artifacts

1. Go to your repository on GitHub.
2. Click the **Actions** tab.
3. Select **Build Android APK** in the left sidebar.
4. Click **Run workflow** (or simply push to `main`).
5. Once the run completes, click on it and download `vikmix-dj-debug-apk` under **Artifacts**.
